# Preferences, Write-back, Reviewer, ATS Check, Keyword Emphasis (v1.8) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the three skills a place to read the candidate's standing preferences, a rule for writing confirmed facts back to the dossier, a fresh-context reviewer, a mechanical ATS check on the rendered résumé, and a measured keyword-bolding rule.

**Architecture:** All behaviour rules live in `shared/` or a skill's `references/`, so each SKILL.md gains one or two sentences per feature plus a link. One new agent file (`agents/application-reviewer.md`), one new shared reference (`reviewer-brief.md`), one new script (`shared/ats-check.py`), one new flag on `render.py`. Python stays stdlib; pypdf and Poppler are probed at runtime, never required.

**Tech Stack:** Markdown skill definitions; static HTML + headless Chrome for PDF; Python 3 stdlib for scripts and tests.

**Spec:** [docs/specs/2026-10-19-v1.8-preferences-reviewer-ats-design.md](../specs/2026-10-19-v1.8-preferences-reviewer-ats-design.md)

## Global Constraints

- **Python is stdlib only.** Optional extractors are imported inside functions and their absence is a reported state, never an error.
- **The layering rule:** nothing in `shared/` may link into a skill's `references/`. A skill may link up into `shared/`. Enforced by `scripts/check-links.py`.
- **Every task ends with `python3 scripts/check-links.py` exiting 0** and, from Task 3 on, with all test scripts green:
  `python3 scripts/test-render.py && python3 scripts/test-html-to-md.py && python3 scripts/test-ats-check.py && python3 scripts/check-links.py`
- **Tests never run Chrome.** Page-size and ATS behaviour are tested on strings and fake extractors.
- **`scripts/fixtures/resume-template.golden.md` must not change.**
- **All example data is fictional** (`example.com`, `555-01xx`), matching `examples/sample-run.md`.
- **SKILL.md files stay short.** Mechanics go to `shared/` or `references/`; `skills/resume-optimizer/SKILL.md` stays under about 110 lines.
